# Code of Conduct

Pryvance adopts the [Contributor Covenant 3.0](https://www.contributor-covenant.org/version/3/0/) as the baseline code of conduct for project spaces.

## Our standard

Participation in Pryvance should be professional, respectful, and constructive. In particular:

- engage honestly and in good faith;
- respect different viewpoints and experiences;
- give and receive technical feedback without personal attacks;
- respect clearly stated boundaries;
- do not harass, discriminate against, threaten, intimidate, or deliberately demean others;
- do not publish another person's private information without permission;
- do not expose real Household financial, identity, tax, credential, recovery, or other sensitive data in project spaces;
- credit sources and contributors appropriately;
- keep commercial promotion and unrelated solicitation out of project discussions.

The complete Contributor Covenant 3.0 terms, including its encouraged and restricted behaviors, scope, and enforcement guidance, apply to this project.

## Scope

This Code of Conduct applies to the Pryvance repository and other official project spaces, and when someone is acting as an official representative of the project.

## Reporting

Report conduct concerns privately to the project maintainer using the private contact methods published on the maintainer's GitHub profile. Do not open a public issue containing sensitive conduct reports or personal information.

Reports will be reviewed as privately as practical. The maintainer may remove content, restrict participation, issue warnings, temporarily suspend participation, or permanently exclude participants when necessary to protect the project community.

Security vulnerabilities are not Code of Conduct reports. Follow [`SECURITY.md`](SECURITY.md) for security reporting.
