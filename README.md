# Pryvance

Private, local-first household financial intelligence.

Pryvance is a self-hosted household finance platform for banking, budgeting, shared obligations, investments, property, receipts, financial documents, and local AI-assisted analysis.

The repository is being bootstrapped. Architecture and design records live under [`docs/`](docs/) and the canonical domain vocabulary lives in [`CONTEXT.md`](CONTEXT.md).

The interactive product reference is available as a self-contained file at [`prototype/index.html`](prototype/index.html). It is a prototype/reference artifact; durable architecture decisions remain under `docs/`.
