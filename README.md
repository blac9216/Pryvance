# Pryvance

Private, local-first household financial intelligence.

Pryvance is a self-hosted household finance platform for banking, budgeting, shared funding, forecasting, investments, property, insurance, receipts, financial documents, tax organization, and AI-assisted analysis.

One Pryvance installation represents one Household. The target architecture supports arbitrary People, children, Financial Entities, Assets, selective privacy/sharing, partial data coverage, multi-currency reporting, provider-neutral integrations, and encrypted offsite recovery.

The feature-complete target architecture approved so far lives under [`docs/`](docs/), and canonical domain vocabulary lives in [`CONTEXT.md`](CONTEXT.md). The [delivery roadmap](docs/explanation/roadmap.md) sequences implementation of that architecture; it does not define a smaller MVP-only design.

The interactive product reference is available at [`prototype/pryvance-prototype.html`](prototype/pryvance-prototype.html). It is a visual/product reference artifact; durable architecture decisions remain authoritative when the prototype and design set differ.
