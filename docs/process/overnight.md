# Overnight limits

Standing rules for unattended runs:

- work only on issues already planned, sequenced, and safe to dispatch under the `area:*` conflict locks;
- do not perform destructive or irreversible actions against external/provider systems or real Household data;
- use local/test resources unless a `*.local.md` instruction explicitly authorizes another environment;
- do not invent credentials, owner decisions, security exceptions, or architecture changes to keep a run moving;
- when credentials, account-owner actions, ambiguous design choices, or unsafe cross-area conflicts block progress, apply `help`, record the blocker on GitHub, and continue only with independent work;
- do not broaden an issue merely to consume unattended time; file out-of-scope findings through the normal deferred-workflow path.
